# Rexar Translation Platform
منصة الترجمة الذكية وفائقة السرعة، قابلة للتثبيت الفوري على خادمك أو جهازك الشخصي، مع مرونة التبديل بين المحركات السحابية والتشغيل المحلي (Offline) ولوحة إدارة متكاملة.
---

## 🚀 التثبيت السحابي التلقائي (Ubuntu / Debian VPS)
للتثبيت والتشغيل الفوري بأمر واحد:
```bash
curl -sSL https://tr.rexar.net/cdn/2026/install.sh | sudo bash
```

---

## 💻 التشغيل على الكمبيوتر الشخصي محلياً (Local PC)

### 1. استنساخ المستودع والدخول للمجلد:
```bash
git clone https://github.com/rexarsystems/rexar-translation.git
cd rexar-translation
```

### 2. التشغيل بالحاويات بأمر واحد (Docker Compose):
```bash
docker compose up -d
```
ثم افتح المتصفح مباشرة على: `http://localhost:38983`
